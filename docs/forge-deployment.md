# Laravel Forge Deployment Notes

Target domain:

- fantasyshred.com

## Recommended Stack

- Ubuntu 24.04 LTS
- Nginx
- Python 3.11+
- Git
- Supervisor (future crawler agents)

## Suggested Directory Layout

```text
/home/forge/fantasyshred.com
├── archive
├── collectors
├── gallery_site
├── public
├── scripts
└── .venv
```

## Initial Forge Site Type

Use:
- Generic PHP/Laravel site OR static Nginx site

The actual rendered archive is static HTML generated by Python.

## Deployment Script

Use deploy/forge_deploy.sh as the Forge deployment script.

## Important Rights Guidance

Do not bulk republish copyrighted trail maps or photography without:

1. explicit permission,
2. public-domain confirmation, or
3. licensing review.

Prefer:
- metadata
- source links
- thumbnails where permitted
- citations
